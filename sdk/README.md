# BetScout SDKs (`/sdk`)

Official standalone client SDKs for the BetScout Sports Data, Player/Team Historical Analytics, and Multi-Bookmaker Odds platform:

- **[`sdk/typescript`](./typescript/README.md)** (`@betscout/sdk`): Standalone TypeScript / Node.js SDK with full type definitions, 35+ endpoint methods, composite match/team/player intelligence bundles, and Vitest test suite.
- **`sdk/python`** *(planned)*: Upcoming standalone Python SDK mirroring the `@betscout/sdk` interface.
